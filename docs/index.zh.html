new-project-planner

一个 skill，把 AI 助手变成面向大学生和学得快的新手的 Vibe Coding 教练——从一个模糊想法，走到一个已上线、能写进简历的作品。

查看 GitHub 仓库 怎么安装

它做什么

你只说一句"我想做一个课程表网站"，别的什么都没说。AI 不会倒出一大堆代码，而是变成一位教练：

先弄清需求在写任何代码之前，先定好目标和最小第一版。
把你放进学习路径HTML/CSS → JavaScript → git → 部署 → 数据与 API → 进阶。缺哪一级，就教哪一级。
把真实工程带进来第一天就用 git、尽早部署、功能需要时就上 API 和数据库。
一次一小步每轮只交一个具体小任务；跟得上就给你更大块。
顺手教提示词7 个可直接复制的模板，从规划到代码审查都有。
绝不丢进度每条回复结尾附一张进度卡，换新对话也能接着做。

学习路径

每一级 = 一项技能 + 一个能证明它的项目：

  • 1 · HTML/CSS 个人主页 → 一个别人能打开的链接
  • 2 · JavaScript 习惯打卡 / GPA 计算器 → 浏览器里能跑
  • 3 · git/GitHub 每个项目都在仓库里 → 干净的历史
  • 4 · 部署 Vercel / Netlify / GitHub Pages → 能写进简历的网址
  • 5 · 数据与 API JSON、SQLite → 刷新不丢的真实数据
  • 6 · 进阶 React、FastAPI 或大模型 API → 一个全栈简历作品

看一段示范

你我想做一个我们学校的课程表网站。
教练好选题。三个小问题：
1. 第一版应该做什么？
2. 还有谁会用它？
3. 你已经会什么——任何语言、git 或终端？
你第一版：显示本周课程，能手动添加和删除。先给我自己用。写过一点 HTML，没用过 git。
教练清楚了。第一版 = 一个页面：添加课程、看到周课表、保存在浏览器里。第一版不做：账号、分享、从教务系统导入。

按学习路径，你大概在第 2 级——接下来补 JavaScript，过程中我们会加上 git 和部署。

计划：第 0 阶段定范围 → 1 骨架 + git 仓库 → 2 周课表网格 → 3 添加/删除课程 → 4 浏览器存储 → 5 打磨 + 测试 → 6 部署到 Vercel + 自定义域名。

现在只做一件事：建好项目文件夹并建一个 git 仓库。做完告诉我，我带你下一步。
进度卡
- 项目：课程表网站
- 阶段：第 1/6 阶段——骨架 + git 仓库
- 已完成：定好第一版范围
- 现在：建文件夹、建 git 仓库
- 下一步：做周课表网格

快捷指令

  • /start 从想法出发，定第一版范围
  • /breakdown 拆成阶段、任务和验收标准
  • /next 只告诉我现在最该做的一件事
  • /teach-prompt 教我怎么写下一条提示词
  • /check 检查项目进度和遗漏
  • /error 进入报错排查模式
  • /explain 逐行解释我贴的代码
  • /ideas 推荐一个符合我水平的项目
  • /teach 讲透一个概念，附练习
  • /review 审查我的代码，给理由
  • /stack 对比技术选型并推荐
  • /retrospective 复盘我学到了什么

安装

Codex —— 一条命令

下载仓库后运行：

bash install.sh

或手动复制，让文件位于 ~/.codex/skills/new-project-planner/SKILL.md。

DeepSeek Harness

把 new-project-planner 文件夹放进项目里的 .dsh/skills 或 .agents/skills 目录，或者放进 ~/.dsh/skills。

Claude Code / Cursor

把文件夹放进对应工具的 skills 目录（例如 ~/.claude/skills/，或 Cursor 项目里的 .agents/skills）。

使用

开新对话，说一句模糊想法，比如"我想做一个课程表网站。"如果 skill 没有自动加载，就说"使用 new-project-planner 这个 skill。"
