new-project-planner

你见过同学晒出自己做的网站，心想：我也想做——但我到底从哪开始？这个 skill 把 AI 变成带你走到终点的教练。每个项目的终点，都是一个全世界都能打开的真实网址。

查看 GitHub 仓库 怎么安装

给这样的你

  • 你有没有见过同学晒出自己做的网站，心想：我也想做——但我根本不知道从哪开始？
  • 你想要的是一个任何人能打开的公开网址，而不是一个只能在自己电脑上打开的本地网页吗？
  • 你想跳过那些玩具教程，做一个真正能写进简历的东西吗？

只要你对其中任何一句点了头，这个 skill 就是为你准备的。它把 AI 变成一位会把这些话问回给你的教练——然后带你从一个模糊想法，走到一个上线运行的项目。

它做什么

先弄清需求在写任何代码之前，先定好目标和最小第一版。
把你放进学习路径HTML/CSS → JavaScript → git → 部署 → 数据与 API → 进阶。缺哪一级，就教哪一级。
真实部署第 2 阶段就首次部署，最终成果永远是一个公网网址——绝不只是本地网页。
提高标准先能跑、再好看、最后惊艳：干净界面、深色模式、真实数据、自定义域名。
顺手教提示词9 个可直接复制的模板，从规划到部署都有。
绝不丢进度每条回复结尾附一张进度卡，换新对话也能接着做。

学习路径

每一级 = 一项技能 + 一个能证明它的项目：

  • 1 · HTML/CSS 个人主页 → 一个别人能打开的链接
  • 2 · JavaScript 习惯打卡 / GPA 计算器 → 浏览器里能跑
  • 3 · git/GitHub 每个项目都在仓库里 → 干净的历史
  • 4 · 部署 Vercel / Netlify / GitHub Pages → 能写进简历的网址
  • 5 · 数据与 API JSON、SQLite → 刷新不丢的真实数据
  • 6 · 进阶 React、FastAPI 或大模型 API → 一个全栈简历作品

看一段示范

你我想做一个我们学校的课程表网站。
教练好直觉。先对个暗号：你有没有见过同学晒出自己做的网站，心想"我也想要——但我到底从哪开始"？如果有，这个项目就是你的追赶起点。三个问题：
1. 第一版应该做什么？
2. 还有谁会用它？
3. 你已经会什么——任何语言、git 或终端？
你第一版：显示本周课程，能手动添加和删除。先给我自己用。写过一点 HTML，没用过 git。
教练清楚了。第一版 = 一个页面：添加课程、看到周课表、保存在浏览器里。第一版不做：账号、分享、从教务系统导入。

按学习路径，你大概在第 2 级——接下来补 JavaScript。注意部署是必选项，不是可选项：从第 2 阶段起你就有一个真实公网网址。

计划：第 0 阶段定范围 → 1 骨架 + git 仓库 → 2 首次部署（hello-world 页面放到公网网址）→ 3 周课表网格 → 4 添加/删除课程 → 5 浏览器存储 → 6 打磨、测试、自定义域名，然后把链接分享出去。

现在只做一件事：建好项目文件夹并建一个 git 仓库。做完告诉我，我带你下一步。
进度卡
- 项目：课程表网站
- 阶段：第 1/6 阶段——骨架 + git 仓库
- 已完成：定好第一版范围
- 现在：建文件夹、建 git 仓库
- 下一步：首次部署——hello-world 页面放到公网网址

安装

Codex —— 一条命令

下载仓库后运行：

bash install.sh

或手动复制，让文件位于 ~/.codex/skills/new-project-planner/SKILL.md。

DeepSeek Harness

把 new-project-planner 文件夹放进项目里的 .dsh/skills 或 .agents/skills 目录，或者放进 ~/.dsh/skills。

Claude Code / Cursor

把文件夹放进对应工具的 skills 目录（例如 ~/.claude/skills/，或 Cursor 项目里的 .agents/skills）。

使用

开新对话，说一句模糊想法，比如"我想做一个课程表网站。"如果 skill 没有自动加载，就说"使用 new-project-planner 这个 skill。"
