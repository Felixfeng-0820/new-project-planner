new-project-planner

一个 skill，把 AI 助手变成耐心陪完全新手做项目的 Vibe Coding 教练。

查看 GitHub 仓库 怎么安装

它做什么

你只说一句"我想做一个网站"，别的什么都没说。AI 不会倒出一大堆代码，而是变成一位教练：

先弄清需求在写任何代码之前，先定好目标和最小第一版。
再拆解项目把项目拆成清晰的阶段，每阶段都有"怎么算完成"的标准。
一次一小步每次只交给你一个 5～20 分钟的小任务，做完才继续。
顺手教提示词教你怎么给 AI 写提示词，附可直接复制的模板。
什么都讲明白先讲人话再讲术语，报错也能变成一堂课。
帮你记住进度每条回复结尾附一张进度卡，换对话也不丢项目。

看一段示范

你我想做一个网站。
教练好！写代码之前，先问四个小问题：
1. 网站是给谁用的？
2. 它最重要的一件事是什么？
3. 第一版肯定不需要什么？
4. 最后希望它在哪运行？
你是我的摄影作品集，别人能看照片、能联系我。不要支付功能。以后想放到网上。
教练清楚了，这就是一个好的最小版：一个页面，展示你的照片 + 一个联系方式。第一版不做：评论、多页面、后台、支付。

计划：第 0 阶段定范围 → 第 1 阶段建文件 → 第 2 阶段页面结构 → 第 3 阶段样式 → 第 4 阶段放真实照片 → 第 5 阶段本地测试 → 第 6 阶段上线。

现在只做一件事：建好项目文件夹和一个空的 HTML 文件。做完告诉我，我带你下一步。
进度卡
- 项目：摄影作品集
- 阶段：第 1/6 阶段 — 建项目文件
- 已完成：定好最小版范围
- 现在：建文件夹和一个空 HTML 文件
- 下一步：搭页面结构

快捷指令

  • /start 从想法出发，定第一版范围
  • /breakdown 拆成阶段、任务和验收标准
  • /next 只告诉我现在最该做的一件事
  • /teach-prompt 教我怎么写下一条提示词
  • /check 检查项目进度和遗漏
  • /error 进入报错排查模式
  • /explain 逐行解释我贴的代码
  • /ideas 推荐一个练手项目
  • /retrospective 复盘我学到了什么

安装

Codex —— 一条命令

下载仓库后运行：

bash install.sh

或手动复制，让文件位于 ~/.codex/skills/new-project-planner/SKILL.md。

DeepSeek Harness

把 new-project-planner 文件夹放进项目里的 .dsh/skills 或 .agents/skills 目录，或者放进 ~/.dsh/skills。

Claude Code / Cursor

把文件夹放进对应工具的 skills 目录（例如 ~/.claude/skills/，或 Cursor 项目里的 .agents/skills）。

使用

开新对话，说一句模糊想法，比如"我想做一个网站。"如果 skill 没有自动加载，就说"使用 new-project-planner 这个 skill。"
