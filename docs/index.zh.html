Big Jump

一句模糊想法进，一个验证过的产品出。把想法丢给 AI——它自己拆解、自己把整个项目建出来、拿一份书面验收清单检查自己的工作，并在你的账号连好的那一刻上线公网网址。诚实——绝不靠假装。

查看 GitHub 仓库 怎么安装

给这样的你

  • 你有没有见过同学晒出自己做的网站，心想：我也想做——但我根本不知道从哪开始？
  • 你想要的是一个任何人能打开的公开网址，而不是一个只能在自己电脑上打开的本地网页吗？
  • 你想跳过那些玩具教程，做一个真正能写进简历的东西吗？

只要你对其中任何一句点了头，这个 skill 就是为你准备的。它把 AI 变成自主执行的建设者：一句模糊想法进，一个已部署的产品出——每个模块做完还附一小段讲解。

它怎么工作

自动跑工作流你说一句模糊想法，它用一行说明假设、给一句方向、列出阶段——每个阶段带一行书面完成标准——然后立刻开工。不采访，不在每步后问"继续吗？"。
先验证再声称走主路径、试奇怪输入、重载证明持久化、盯控制台的报错和 404——每个阶段还跑一个小而可重复的检查脚本。检查通过才算完成——不是按钮有反应就算完成。
做完才讲每个阶段一段 4 行回顾：做了什么、为什么这样做、你学到了什么、验证了什么。输出稀疏、没有进度卡，讲完自动继续。
只在真卡点停它修不动的报错、缺密钥或账号、只有你能拍板的选择、花钱。
诚实地部署建仓库或部署之前先征得你同意——授权不等于许可。然后验证网址，或者交给你一份简短清单。绝不声称一个它没打开过的网址。
保护你的工作绝不 reset 或覆盖你未提交的改动，绝不 force-push；只回滚它自己的修改。
适配你的环境有终端就自己跑；纯聊天里就把文件和精确命令交给你——绝不声称跑过它跑不了的东西。
帮你找到方向不知道写啥？一套问题猎取法 + 三问指路器，把"我不知道"变成一个有人用的产品。

看一段工作流示范

你我想做一个 AI 工具：上传 PDF，得到摘要，还能对内容提问。
Big Jump假设：单页网页应用，一次一个 PDF，没有账号。方向：一个"AI 文档阅读器"——上传 → 摘要 → 提问。计划：6 个阶段。现在开工。

[第 1 阶段：建项目文件夹和 git 仓库，提交。]

第 1 阶段回顾：建好了文件夹和 git 仓库。为什么：git 保存每个版本，任何操作都不会永久弄坏项目。你学到：一次提交就是一个存档点。

[第 2 阶段：部署 hello-world 页面，报出网址。]

第 2 阶段回顾：你的第一个页面已在 [网址] 上线。为什么：尽早部署意味着从第一天就有真实网址。你学到：部署就是把文件放到服务器上，让别人能打开。

[第 3～6 阶段照此进行——建设、验证、提交、回顾、继续——全程不问。]
收工完成——AI 文档阅读器已在 [网址] 上线。它能上传 PDF、生成摘要、并回答关于内容的问题。升级方向：(1) 多文件库，(2) 用数据库记住历史文档，(3) 加账号让同学也能用。想做哪个？还是直接开始你的下一个项目？

快捷指令

  • /pause 停下自动流程，等我
  • /next 继续下一步
  • /explain 逐行解释我贴的代码
  • /review 审查我的代码，给理由
  • /error 一步步排查我的报错
  • /deploy 带我一步步把项目放上网
  • /showcase README、截图、演示链接、简历话术
  • /teach 讲透一个概念，附练习
  • /stack 对比技术选型并推荐
  • /ideas 不知道写啥？跑一遍方向指路器
  • /retrospective 复盘我学到了什么

安装

Codex —— 一条命令

下载仓库后运行：

bash install.sh

或手动复制，让文件位于 ~/.codex/skills/big-jump/SKILL.md。

DeepSeek Harness

把 big-jump 文件夹放进项目里的 .dsh/skills 或 .agents/skills 目录，或者放进 ~/.dsh/skills。

Claude Code / Cursor

把文件夹放进对应工具的 skills 目录（例如 ~/.claude/skills/，或 Cursor 项目里的 .agents/skills）。

使用

开新对话，说一句模糊想法，比如"我想做一个把 PDF 变成可提问摘要的 AI 工具。"如果 skill 没有自动加载，就说"使用 big-jump 这个 skill。"
