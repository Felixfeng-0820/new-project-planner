new-project-planner

An Agent Skill that turns your AI assistant into a vibe-coding coach for college students and smart beginners — from a vague idea to a deployed, portfolio-worthy project.

View on GitHub How to install

What it does

You say "I want to build a course-schedule website" and nothing else. Instead of dumping a wall of code, your AI becomes a coach who:

Clarifies firstAgrees on the goal and a minimal first version before writing any code.
Places you on a learning pathHTML/CSS → JavaScript → git → deployment → APIs/data → going deeper. Teaches the rung you are missing.
Builds real engineering ingit from day one, deployment early, an API or database when the feature needs it.
One step at a timeExactly one small task per turn — bigger chunks when you keep up.
Teaches prompts7 ready-to-copy prompt templates, from planning to code review.
Never loses your placeEvery reply ends with a progress card, so a new chat can resume where you left off.

The learning path

Each rung is a skill plus a project that proves it:

  • 1 · HTML/CSS a personal page → a link people can open
  • 2 · JavaScript a habit tracker or GPA calculator → works in the browser
  • 3 · git/GitHub every project in a repo → clean history
  • 4 · Deployment Vercel / Netlify / GitHub Pages → a resume-ready URL
  • 5 · Data & APIs JSON, SQLite → real data that survives refresh
  • 6 · Going deeper React, FastAPI, or an LLM API → a full-stack portfolio piece

See it in action

YouI want to build a course-schedule website for my campus.
CoachGood pick. Three quick questions:
1. What should v1 do?
2. Who else will use it?
3. What do you already know — any language, git, or the terminal?
Youv1: show this week's classes, add or delete courses by hand. Just me for now. I've written a little HTML. No git.
CoachClear. v1 = one page: add courses, see the week grid, saved in the browser. Not in v1: accounts, sharing, importing from the school system.

You are around rung 2 of the learning path — JavaScript next, and we will add git and deployment along the way.

The plan: Phase 0 scope → 1 scaffold + git repo → 2 week grid → 3 add/delete courses → 4 browser storage → 5 polish + test → 6 deploy to Vercel + custom domain.

Do only this now: create the project folder and start a git repo. Tell me when it is done and I will take you to the next step.
Progress card

Quick commands

  • /start define the first-version scope
  • /breakdown phases, tasks, acceptance criteria
  • /next the single most useful thing to do now
  • /teach-prompt how to write your next AI prompt
  • /check review progress and gaps
  • /error troubleshoot an error like a teacher
  • /explain explain pasted code line by line
  • /ideas suggest a project matched to your level
  • /teach explain a concept, with exercises
  • /review review your code, with reasons
  • /stack compare tech options and recommend
  • /retrospective summarize what you learned

Install

Codex — one command

Download the repository and run:

bash install.sh

Or copy manually so the file sits at ~/.codex/skills/new-project-planner/SKILL.md.

DeepSeek Harness

Put the new-project-planner folder into .dsh/skills or .agents/skills in your project, or into ~/.dsh/skills.

Claude Code / Cursor

Put the folder into the tool's skills directory (for example ~/.claude/skills/, or the .agents/skills project folder).

Use it

In a new chat, just say a vague idea, like "I want to build a course-schedule website." If the skill does not load automatically, say "Use the new-project-planner skill."
