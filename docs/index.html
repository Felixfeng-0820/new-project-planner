For students like you

  • Have you ever seen a classmate show off a website they built by themselves, and thought: I want to do that too — but I have no idea where to start?
  • Do you want a project with a real URL that anyone can open — not a page that only runs on your own laptop?
  • Do you want to skip the toy tutorials and build something you can actually put on your resume?

If you nodded to any of these, this skill is for you. It turns your AI assistant into a coach who asks these questions back at you — and then gets you from a vague idea to a live, deployed project.

The learning path

Each rung is a skill plus a project that proves it:

  • 1 · HTML/CSS a personal page → a link people can open
  • 2 · JavaScript a habit tracker or budget calculator → works in the browser
  • 3 · git/GitHub every project in a repo → clean history
  • 4 · Deployment Vercel / Netlify / GitHub Pages → a resume-ready URL
  • 5 · Data & APIs JSON, SQLite → real data that survives refresh
  • 6 · Going deeper React, FastAPI, or an LLM API → a full-stack portfolio piece

Quick commands

  • /start define the first-version scope
  • /breakdown phases, tasks, acceptance criteria
  • /next the single most useful thing to do now
  • /teach-prompt how to write your next AI prompt
  • /check review progress and gaps
  • /error troubleshoot an error like a teacher
  • /explain explain pasted code line by line
  • /ideas no idea what to build? run the direction picker
  • /teach explain a concept, with exercises
  • /review review your code, with reasons
  • /stack compare tech options and recommend
  • /deploy put your project online, step by step
  • /showcase README, screenshot, demo link, resume bullet
  • /retrospective summarize what you learned

Install

Codex — one command

Download the repository and run:

bash install.sh

Or copy manually so the file sits at ~/.codex/skills/big-jump/SKILL.md.

DeepSeek Harness

Put the big-jump folder into .dsh/skills or .agents/skills in your project, or into ~/.dsh/skills.

Claude Code / Cursor

Put the folder into the tool's skills directory (for example ~/.claude/skills/, or the .agents/skills project folder).

Use it

In a new chat, just say a vague idea, like "I want to build an AI tool that turns PDFs into summaries I can ask questions about." If the skill does not load automatically, say "Use the big-jump skill."
