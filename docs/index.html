new-project-planner

An Agent Skill that turns your AI assistant into a patient vibe-coding coach for complete beginners.

View on GitHub How to install

What it does

You say "I want to build a website" and nothing else. Instead of dumping a wall of code, your AI becomes a coach who:

Clarifies firstAgrees on the goal and a minimal first version before writing any code.
Breaks it downSplits the project into clear phases, each with a definition of done.
One small stepHands you exactly one 5–20 minute task at a time, then waits.
Teaches promptsShows you how to write good AI prompts, with ready-to-copy templates.
Explains everythingPlain language first, technical terms second. Errors become lessons.
Remembers with youEnds every reply with a progress card so you never lose your place.

See it in action

YouI want to build a website.
CoachNice! Before any code, four quick questions:
1. What is the website for, and who will visit it?
2. What is the one most important thing it must do?
3. Anything it definitely does NOT need in the first version?
4. Where should it live in the end?
YouIt's a portfolio for my photography. People should see my photos and contact me. No payments. On the internet, eventually.
CoachClear — that is a good v1: one page that shows your photos and has a contact link. Not in v1: comments, multiple pages, an admin panel, payments.

The plan: Phase 0 scope → Phase 1 create files → Phase 2 page structure → Phase 3 looks → Phase 4 real photos → Phase 5 test → Phase 6 deploy.

Do only this now: create the project folder and one empty HTML file. Tell me when it is done and I will take you to the next step.
Progress card
- Project: photography portfolio
- Phase: 1 of 6 — create the project files
- Done: agreed on v1 scope
- Now: create the folder and one empty HTML file
- Next: build the page structure

Quick commands

  • /start define the first-version scope
  • /breakdown phases, tasks, acceptance criteria
  • /next the single most useful thing to do now
  • /teach-prompt how to write your next AI prompt
  • /check review progress and gaps
  • /error troubleshoot an error like a teacher
  • /explain explain pasted code line by line
  • /ideas suggest a beginner project to build
  • /retrospective summarize what you learned

Install

Codex — one command

Download the repository and run:

bash install.sh

Or copy manually so the file sits at ~/.codex/skills/new-project-planner/SKILL.md.

DeepSeek Harness

Put the new-project-planner folder into .dsh/skills or .agents/skills in your project, or into ~/.dsh/skills.

Claude Code / Cursor

Put the folder into the tool's skills directory (for example ~/.claude/skills/, or the .agents/skills project folder).

Use it

In a new chat, just say a vague idea, like "I want to build a website." If the skill does not load automatically, say "Use the new-project-planner skill."
